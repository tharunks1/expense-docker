# Expense Management Application

A simple web application to manage and track daily expenses.

## Features

* Add new expenses
* View all expenses
* Store expense information in a database
* User-friendly web interface

## Technologies Used

* React.js
* Java/Spring Boot
* MySQL
* Nginx

## Project Structure

```text
frontend/
backend/
database/
nginx/
```

## How It Works

1. User enters expense details.
2. Frontend sends the request to the backend.
3. Backend processes the request.
4. Data is stored in MySQL.
5. Expenses are displayed on the UI.

## Learning Outcomes

* Frontend and backend integration
* REST API development
* Database connectivity
* Nginx configuration
* Application troubleshooting
